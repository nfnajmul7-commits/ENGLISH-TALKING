# LingoPulse — Interactive AI Language Learning App (Android)

LingoPulse is a native Android language learning app built with Kotlin and Jetpack Compose featuring an animated lip-syncing AI tutor avatar (*Aria*), structured native-language lessons, illustrated role-play scenarios, voice practice, and progress tracking.

## Download APK from GitHub (Android Phone)

1. Push this project to your GitHub repository (`main` or `master` branch).
2. Open the **Actions** tab on GitHub and wait 2–4 minutes for **Build & Release Android APK** to show a green checkmark.
3. To install directly on your phone:
   - **Easiest (Direct APK):** Open the **Releases** section of your repository and tap **`LingoPulse.apk`** to download and install.
   - **Alternative (Actions Artifact):** Open the completed workflow run under **Actions**, scroll to **Artifacts**, download **`LingoPulse-APK`**, unzip it, and tap `LingoPulse.apk`.
